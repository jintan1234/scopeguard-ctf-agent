# Changelog

- Added task-scoped authorization and exact host/port validation.
- Added the 31-tool `ctf-control` MCP server.
- Added budget, retry and no-progress control.
- Added evidence ledgers, artifact hashing and reproducible reports.
- Added Playwright scope proxy and browser-action budget bridge.
- Added token-authenticated Docker broker and sandbox profiles.
- Added local regression tests.
- Added one-command Windows and Linux/macOS bootstrap scripts.
- Added automatic Codex MCP configuration and optional project trust helpers.
- Added real case studies for ret2libc, Android native/DEX, custom VM,
  SQL-injection CVE reproduction, sqli-labs, Windows PE reverse engineering,
  Base64/XOR and fake-encrypted ZIP.
- Added workflow, prompt, report-format and bootstrap documentation.
- Added third-party notices, preserved MIT/Apache-2.0/GPL-2.0 texts, and
  documented the unavailable Conly-Zy/CTF-Agent source and unknown license.
